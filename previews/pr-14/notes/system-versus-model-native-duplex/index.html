System duplex versus model-native duplex for an AI voice assistant

Project period · September 2026

Composing local hearing, echo control and speech around the existing agent traded elegance for control.

  • Voice
  • Agent Architecture
  • WebRTC
  • Mlx

In brief

  • A native speech-to-speech model offered the neatest diagram but weak control over interruption and agent state.
  • We instead composed WebRTC echo control, VAD, streaming ASR, OpenClaw steering and cancellable TTS.
  • Controlled echo tests achieved 70.9 dB suppression and zero false voice detections.
  • Warm local TTS produced first audio in about 105–129 ms; typical final ASR took 0.24–0.60 seconds.
  • The modular system preserved Tiggy’s existing memory, tools and personality.

Native duplex models absorb, reason and speak in one continuous loop. Our alternative joined specialist components around Tiggy, an existing stateful OpenClaw agent whose memory, tools and permissions already mattered. The modular route looked less magical, but it worked better for the job.

Keep OpenClaw as the stateful agent

The working path begins with iPhone Safari’s WebRTC capture and acoustic echo cancellation. Server-side voice activity detection and an energy gate reject noise. A 0.6B Nemotron model transcribes speech; queueMode=steer injects it into the active OpenClaw run or starts a normal turn. Gateway deltas feed sentence-sized chunks to Kokoro, whose British female output remains cancellable while listening continues.

This preserves one agent state machine. Speech does not create a second memory, tool policy or personality.

Measure the seams

In controlled tests, echo suppression reached 70.9 dB with zero false VAD frames. Speech onset was detected in 60–80 ms before the live noise-resilient threshold was raised to 120 ms. Final ASR usually took 0.24–0.60 seconds; warm TTS first audio took about 105–129 ms. Both speech models together used about 2.0 GiB resident memory.

An active-run proof started a 20-second tool call, admitted an interruption while that call was still running and preserved the same run identity. The original answer never escaped; the steered answer did. Later, the full Safari/WebRTC path worked from a real iPhone in a noisy kitchen.

The system is not instant. One slow model turn took about 11 seconds to its first usable sentence. Streaming TTS can hide generation tail, not reasoning startup. Yet its interruption behaviour is explicit: confirmed speech cancels queued audio before ASR finishes, then the transcript steers the same agent.

Result

Model-native duplex remains a compelling research direction. System duplex won this deployment because every component had one job and every control seam was inspectable.

Composition bought deterministic barge-in, a chosen voice and continuity with the existing assistant. The price is more plumbing. For a personal agent whose identity and permissions already matter, that is a sensible trade.
