Building a living LAN inventory without aggressive scanning

Project period · May–September 2026

ICMP, ARP and reverse lookup produced a useful household inventory while preserving uncertainty and avoiding broad port scans.

  • Home Lab
  • Networking
  • Inventory
  • Security

In brief

  • We wanted a useful household device inventory without treating the LAN like a penetration-test target.
  • The first pass used an ICMP sweep, neighbour/ARP tables and local reverse lookup only.
  • Observations recorded interface and evidence type instead of pretending every address was definitive.
  • Dual-homed machines, sleeping devices, private Wi-Fi MACs and isolated subnets remained explicit caveats.
  • Later project work enriched the inventory from configuration and device evidence rather than rescanning everything aggressively.

A home network inventory is always incomplete. The honest goal is a living evidence set, not a frozen list labelled “all devices”.

A deliberately light first pass

The scan sent ordinary reachability probes across one local subnet, then collected the Mac’s neighbour tables and attempted local name resolution. It did not enumerate services or sweep ports. Results distinguished devices that answered from addresses seen only in ARP.

That difference matters. ARP proves that a local interface recently associated an address with a link-layer identity. It does not prove the device is awake now, who owns it or whether a randomised MAC will persist. ICMP silence does not prove absence; many devices ignore echo requests.

Record the awkward cases

The scanning Mac itself had Ethernet and Wi-Fi on the same subnet, so some neighbours appeared through both interfaces. Other machines were dual-homed. Phones and laptops could use private Wi-Fi MACs. One gaming PC lived behind a separate firewall interface and could not be attributed from the main LAN at all.

The inventory therefore kept source interfaces, observed names and status notes. Unknown remained a valid value. Device identity was strengthened later through DHCP leases, access-point associations, application configuration, labels and hands-on project work.

This also avoided an attractive nuisance: turning one inventory exercise into an unapproved service scan of every family and IoT device. Deeper probes were reserved for a specific troubleshooting task.

Result

The first snapshot was good enough to locate known infrastructure, spot cameras and build a list for refinement. It was not sold as a source of truth.

A living inventory improves by accumulating corroborated observations and expiring stale confidence. Capture what answered, what was merely cached, how it was seen and what remains unreachable from this vantage point. Honest uncertainty is a feature of network documentation.
